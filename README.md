# 🛒 Amazon Product Page — Solo Project Replacement  
*A simplified Amazon‑style product page for a fictional item.*

---

## 🎯 Project Goal  
Build a centered product page for a fictional Amazon listing using HTML + CSS only.  
The page must include a product image, title, description, price, rating, and purchase buttons — all styled using the techniques you’ve learned.

---

## 📐 Requirements  
Every requirement begins with a Guided Link so you can explore any part further if you want.

---

## 🧱 Structure Requirements  
- **Page container** — A parent element wrapping the entire product page.  
- **Product card** — A centered card containing all product information.  
- **Product image** — Must use this image filename:  
  **`images/product.jpg`**  
  Must include this alt text:  
  **“Wireless Noise‑Cancelling Headphones”**  
- **Product title** — Must contain this text:  
  **“Wireless Noise‑Cancelling Headphones”**  
- **Product subtitle** — Must contain this text:  
  **“Premium comfort. Superior sound.”**  
- **Product description** — Must contain  this text:  
  **“Experience immersive audio with cutting‑edge noise cancellation, crystal‑clear highs, and deep, powerful bass. These wireless noise‑cancelling headphones are engineered for comfort, featuring ultra‑soft ear cushions and a lightweight frame designed for long listening sessions. With up to 32 hours of battery life, fast charging support, and seamless Bluetooth connectivity, you can enjoy uninterrupted music, podcasts, and calls throughout your day. Built‑in touch controls make it easy to adjust volume, skip tracks, and manage calls without reaching for your device. Whether you’re commuting, working, or relaxing at home, these headphones deliver premium sound quality and exceptional noise isolation to elevate every moment.”**  
- **Price** — Must contain exactly this text:  
  **“$149.99”**  
- **Price container** — A flexbox container holding the price elements.  
- **Rating** — Must contain this text/image:  
  **“⭐️⭐️⭐️⭐️☆ (4.2 out of 5)”**  
- **Primary button** — Must contain this text:  
  **“Add to Cart”**  
- **Secondary button** — Must contain this text:  
  **“Buy Now”**  
- **Shipping note** — Must contain exactly this text:  
  **“Free shipping on orders over $50.”**

---

## 🎨 Styling Requirements  
- **External CSS link** — All styling must be in a linked CSS file.  
- **Relative image path** — The image must load via a correct relative path.  
- **Alt attribute** — The image must include the required alt text.  
- **Image sizing** — The product image must be visually smaller than its original size.  
- **Border + padding** — The product card must have a border and internal padding.  
- **Flexbox child containers** — Use flexbox for the button group.  
- **Flex item containers** — Ensure each button is treated as a flex item.  
- **Utility class** — Create at least one utility class (e.g., `.text-center`, `.mb-1`, `.flex`).  
- **Justify-content** — Use justify-content to control spacing between the two buttons.  
- **Center the card** — The entire product card must be centered horizontally.  
- **Inheritance** — Use inheritance to center text inside the card.  
- **Colors** — Apply a color palette inspired by Amazon (blue, yellow, white, gray).  
- **Web‑safe fonts** — Use a web‑safe font stack (e.g., Arial, Helvetica, sans-serif).  
- **Margin/padding shorthand** — Use shorthand syntax for margin and padding at least twice.  
- **Make it your own** — Add one small personal touch (color tweak, border style, spacing change).

---

## 🏷 Thematic Requirements  
- **Amazon‑style layout** — Clean, centered, product‑focused.  
- **Amazon‑style buttons** — Buttons must visually resemble Amazon’s style (yellow primary, blue secondary).  
- **Amazon‑style spacing** — Use generous spacing between sections.
